# 対象表シートの作り方

操作してよいスプレッドシートの一覧は、**Google スプレッドシート1枚**で管理する。利用者のパソコンにファイルを配らないため、対象を追加したり書き込み可否を変えたりしても、このシートを直すだけで全員に反映される。

## 作り方

新しいスプレッドシートを1枚作り、最初のタブを `対象表` という名前にする。1行目を見出しにして、次の4列を用意する。

| A: 名前 | B: スプレッドシートID | C: 書き込み可 | D: 備考 |
|---|---|---|---|
| 受注台帳 | `1AbCdEf...` | はい | 日常の読み書き対象 |
| 集計ダッシュボード | `1GhIjKl...` | いいえ | 自動集計。直接書かない |
| 取引先から共有されたシート | `1MnOpQr...` | いいえ | 相手先の持ち物。書き込み厳禁 |

C列は `はい` か `いいえ` のどちらかを入れる。空欄や、それ以外の値は「いいえ」として扱われる（安全側に倒す）。

スプレッドシートIDは、シートのURLの `/d/` と `/edit` に挟まれた部分である。

```
https://docs.google.com/spreadsheets/d/【この部分がID】/edit#gid=0
```

## 共有設定

この対象表シートを、利用者全員に**閲覧者**として共有する。編集権限は配らない（対象の追加や書き込み可否の変更は管理者だけが行う）。

作成したシートのIDを、プラグインの設定項目「対象表のスプレッドシート ID」に入れてもらう。

## 大事なこと

**C列を「いいえ」にすることは、書き込みを止める仕組みではない。** これはスキルへの指示にすぎず、最終的な防波堤にはならない。読ませるだけの相手には、**そのスプレッドシート自体の Drive 共有権限を閲覧者にする**こと。権限で止まっていれば、何が起きても書き込みは失敗する。
