# 管理者の準備（この1枚で完了します）

Claude Code から Google スプレッドシートと Apps Script を操作できるようにするための、管理者側の準備手順です。**作業は一度きりです。** 一度作れば、利用者が何人増えても追加の作業はいりません。

必要なもの: Google Workspace の管理者アカウント。費用はかかりません（Google Cloud の課金設定も不要です）。

所要時間の目安は 30 分程度です。

---

## なぜこの作業が必要なのか

コマンドラインのツールから Google のデータを扱うには、「このツールに、この会社のデータへ触ってよい」という許可の入れ物が要ります。これを OAuth クライアントと呼び、Google Cloud の画面で作ります。Google アカウントを持っているだけでは足りない部分が、ここです。

作るのは1つだけで、それを全員で共有します。

---

## 手順1: Cloud プロジェクトを作る

1. 管理者の Google アカウントで https://console.cloud.google.com/ を開きます
2. 画面上部のプロジェクト選択から「新しいプロジェクト」を選びます
3. 名前は用途がわかるものにします（例: `workspace-cli`）
4. **「組織」または「場所」の欄に、会社のドメイン名が入っていることを確認してください**
5. 「作成」を押します

手順4が特に大事です。ここが「組織なし」になっていると、手順3で必要な設定が選べなくなり、最初からやり直しになります。

---

## 手順2: 使う機能を有効にする

左のメニューから「API とサービス」→「ライブラリ」を開き、次の5つを検索して、それぞれ「有効にする」を押します。

| 名前 | 何に使うか |
|---|---|
| Google Drive API | ファイルの検索とアップロード |
| Google Sheets API | スプレッドシートの読み書き |
| Google Docs API | ドキュメントの読み書き |
| Apps Script API | スクリプトの配置 |
| Service Usage API | 上の機能の状態確認 |

Apps Script を使う予定がなければ下2つは省けますが、あとから足すより今入れておくほうが手間がかかりません。

---

## 手順3: 承認画面を「内部」にする

左のメニューから「API とサービス」→「OAuth 同意画面」を開きます。新しい画面では「Google Auth Platform」という名前です。

1. **「対象」のタブで、ユーザーの種類を「内部」にします**
2. 「ブランディング」のタブで、アプリ名を入れます。ここに入れた名前が、利用者の承認画面に表示されます。「〇〇社 Workspace CLI」のように、社内の人が見て正体がわかる名前にしてください
3. サポートメールに管理者のアドレスを入れます

### ここが一番大事です

「内部」と「外部」で、その後の運用がまったく変わります。

| | 内部 | 外部（テスト中のまま） |
|---|---|---|
| Google の審査 | 不要 | 一般公開には必要。費用がかかる審査まで求められます |
| 使える人数 | 社内なら無制限 | 100 人まで |
| ログインの持ち | 切れません | **7日で切れます**（利用者が毎週ログインし直すことになります） |
| 承認画面 | 通常の画面 | 「このアプリは確認されていません」という警告が出ます |

「内部」が灰色で選べない場合は、手順1でプロジェクトが組織の下に作られていません。プロジェクトを作り直してください。

---

## 手順4: OAuth クライアントを作る

同じ画面の「クライアント」のタブを開き、「クライアントを作成」を押します。

- 種類: **デスクトップアプリ**（「ウェブアプリケーション」ではありません。間違えると認証が通りません）
- 名前: 手順3のアプリ名と揃えておくと、あとで探しやすくなります

作成すると画面にクライアント ID とシークレットが表示されます。「JSON をダウンロード」を押してファイルを保存し、**ファイル名を `client_secret.json` に変えてください。**

---

## 手順5: 組織のアプリ制限を確認する

会社の設定によっては、作ったばかりのクライアントが弾かれます。確認します。

1. https://admin.google.com/ を開きます
2. 「セキュリティ」→「アクセスとデータ管理」→「API の制御」を開きます
3. 「未設定のサードパーティ アプリ」の設定を見ます

「アクセスをブロック」になっている場合は、次を行います。

4. 「サードパーティ アプリのアクセスを管理」→「アプリを追加」→「OAuth アプリ名またはクライアント ID」を選びます
5. 手順4で作ったクライアント ID を検索し、**信頼済み**として登録します

ブロックしていない場合、この手順は不要です。

---

## 手順6: 対象表シートを作る

操作してよいスプレッドシートの一覧を、Google スプレッドシート1枚で管理します。

新しいスプレッドシートを1枚作り、最初のタブの名前を `対象表` にします。1行目を見出しにして、次の4列を用意します。

| A: 名前 | B: スプレッドシートID | C: 書き込み可 | D: 備考 |
|---|---|---|---|
| 受注台帳 | `1AbCdEf...` | はい | 日常の読み書き対象 |
| 集計ダッシュボード | `1GhIjKl...` | いいえ | 自動集計。直接書きません |
| 取引先から共有されたシート | `1MnOpQr...` | いいえ | 相手先の持ち物。書き込み厳禁 |

C 列は「はい」か「いいえ」を入れます。空欄やそれ以外の値は「いいえ」として扱われます。

スプレッドシート ID は、シートの URL の `/d/` と `/edit` に挟まれた部分です。

この対象表シートを、利用者全員に**閲覧者**として共有します。編集権限は配りません。

### 対象表だけに頼らないでください

C 列を「いいえ」にすることは、書き込みを止める仕組みではありません。あくまでツールへの指示であって、最終的な防波堤にはなりません。

**読ませるだけの相手には、そのスプレッドシート自体の共有権限を閲覧者にしてください。** 権限で止まっていれば、何が起きても書き込みは失敗します。

---

## 手順7: 利用者へ配る

利用者ひとりずつに、次の2つを渡します。

| 渡すもの | 渡し方 |
|---|---|
| `client_secret.json` | 社内の Drive で共有します |
| 対象表のスプレッドシート ID | 設定画面に貼り付けてもらう値です |

`client_secret.json` は、**公開の場に置かないでください。** 社外から見えるリポジトリ、公開チャンネル、社外を含む一斉送信のメールは避けます。

デスクトップアプリのシークレットは、Google 自身が「利用者の手元に配るツールでは秘密として扱えない」としているものなので、漏れたらただちに事故という種類のものではありません。それでも社外に置く理由はないので、社内で閉じた経路で配ってください。

---

## 手順8: 利用者へ伝えること

利用者には、次のように伝えれば足ります。

> Claude Code を開いて、次の2行を実行してください。
>
> ```
> /plugin marketplace add https://github.com/HironosukeW/gws-tools-plugin.git
> ```
>
> ```
> /plugin install gws-tools@gws-tools
> ```
>
> 設定画面が開いたら、対象表のスプレッドシート ID を貼り付けます。
> そのあと Claude に「セットアップして」と伝えれば、残りは案内が出ます。
> 途中でブラウザが開いたら、**会社のアカウント**で承認してください。

---

## あとから困らないための記録

次を控えておいてください。利用者から相談が来たときに、ここを見れば原因がわかります。

- Cloud プロジェクトの名前と ID
- OAuth クライアント ID（末尾が `.apps.googleusercontent.com`）
- 対象を「内部」にしたかどうか
- 管理コンソールで信頼済みに登録したかどうか
- 対象表シートの ID と、共有した相手

---

## よくある相談と原因

| 利用者の言うこと | 原因 |
|---|---|
| 「このアプリは確認されていません」と出る | 手順3の対象が「内部」になっていません |
| 「アクセスをブロックされました」と出る | 手順5をやっていません |
| 数日おきにログインし直しになる | 手順3の対象が「外部」のままです |
| コマンドが見つからないと言われる | 利用者側の PATH の問題です。Claude に「Windows でコマンドが見つからない」と伝えれば案内が出ます |
| スプレッドシートが 404 になる | 対象表かそのシートが、その利用者に共有されていません |
